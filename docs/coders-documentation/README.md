# Coder's Documentation

A running engineering log for the actual code being built (the Android pilot app and, later, its backend) — distinct from the `docs/phase-*` product/company documentation and the `docs/mvp-pilot/` design doc. This is where the day-to-day "what did we build, how does it work, what broke and why" record lives.

One file per day of real engineering work:

- [`day-1.md`](day-1.md) — tech stack, exact code flow, full build-to-device story, every bug found and fixed, and what's proven to work vs. still open. Covers taking the pilot from the architecture doc to a working app that captured 472 real transactions from a live device's SMS history.
