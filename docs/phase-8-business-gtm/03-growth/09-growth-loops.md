# Document 09: Growth Loops

## Document Name
Growth Loops

## Purpose
Define the systematic growth-loop framework — the set of inputs that compound into which outputs, and the mechanisms that connect them — underlying the company's growth strategy. This document is the parent framework for Referral (Document 10), Virality (Document 11), and Retention (Document 12), which each specify one loop, or one reinforcing dimension of a loop, in depth.

## Why It Exists
Growth teams that start from tactics (run a referral program, ship a share button, launch a paid campaign) rather than from a loop model tend to produce a pile of disconnected initiatives whose combined effect is unmeasurable and whose interactions are unknown. A growth-loop model forces the opposite discipline: name the loop, name the input that starts it, name the output that either feeds the next cycle or leaks out of the system, and only then decide which tactics best strengthen that specific step. Because this company's Phase 1 Guiding Principles rule out dark patterns, guilt-based engagement, and streak-shaming, the loop model also has to be the place where growth is explicitly separated from manipulation — a loop compounds because the product delivers genuine value repeatedly, not because it exploits a psychological vulnerability. This document exists to be the single map every other Phase 8 growth document is drawn from, so that Referral, Virality, and Retention are recognizably parts of one system rather than three unrelated bets.

## Approximate Page Count
8-10 pages

## Sections
1. **Growth Loop Taxonomy** — the categories of loop this company can plausibly run (content/SEO loop, product-driven/virality loop, paid loop, referral loop, sales-assisted/B2B2C loop), with a one-line definition of each and which pillars (Productivity, Finance, Health) they apply to.
2. **Primary Loop Selection** — which loop(s) are hypothesized as the primary growth engine given the product's nature (a daily-use proactive assistant, not a one-time-use utility), and the reasoning for prioritizing it over alternatives at each company stage (pre-PMF, post-PMF, scale).
3. **Loop Anatomy Model** — the generic structure used to describe every loop in this and downstream documents (input → action → output → reinvestment), so Referral, Virality, and Retention can each be expressed in the same notation and compared on the same terms.
4. **Compounding Mechanics & Loop Math** — the structural logic (not final figures) for how a loop's output-to-input ratio determines whether it compounds, decays, or is flat, and which levers in this product's specific loops most affect that ratio.
5. **Cross-Pillar Loop Interactions** — how a loop triggered in one pillar (e.g., a Finance insight prompting a share) can feed acquisition or retention in another pillar, and how the single-assistant bundling logic from the Business Model document amplifies loop compounding versus three separate single-pillar products.
6. **Loop Health Instrumentation** — what must be measured at each stage of a loop to know whether it is healthy, stalling, or decaying, and how this instrumentation maps onto the Success Metrics Document's North Star and guardrail metrics so loop optimization cannot silently drift toward optimizing an anti-metric.
7. **Anti-Pattern Boundary for Loop Design** — the explicit ruling that no loop step may rely on guilt, fear of missing out, artificial scarcity, or engagement-bait notifications, cross-referenced against the Phase 1 Guiding Principles and the Gamification Philosophy Document's Encouragement-vs-Guilt Test.
8. **Loop Prioritization & Sequencing** — how the company decides which loop to invest in building first, second, and third as it scales, and the criteria (loop maturity, data availability, team capacity) that trigger investment in the next loop.
9. **Loop Ownership Model** — which team or role owns the health of each loop end-to-end, distinct from which team owns a single tactic within it.
10. **Relationship to Downstream Growth Documents** — an explicit map showing which sections of Referral, Virality, and Retention instantiate which loop(s) defined here, so the four documents read as one coherent system.

## Deliverables
- A named, prioritized set of growth loops with the loop-anatomy model applied to each.
- A loop health instrumentation plan mapped to the Success Metrics Document's KPI tree.
- A written anti-pattern boundary statement reviewed against Phase 1 Guiding Principles.
- A loop ownership matrix (loop → owning team/role).
- A sequencing plan showing which loop is invested in at which company stage.
