# Document 08: LTV (Lifetime Value)

## Document Name
LTV (Lifetime Value)

## Purpose
Define the methodology for calculating Customer Lifetime Value, including how retention, expansion (e.g., single-user to household plan), and churn are modeled over time, and how that value is expected to correlate with the depth of trust a user has built with the AI. This document also defines the LTV:CAC ratio target framework used to judge whether growth spend is sustainable. It specifies methodology and directional hypotheses — not final LTV figures, which require real cohort retention data.

## Why It Exists
LTV is the number that ultimately justifies every dollar of CAC, but for a proactive AI life-management product, LTV is not just a function of subscription price and churn — it is plausibly a function of how far a user has progressed up the Phase 5 Proactivity Ladder, since a user who has granted the AI more autonomy has both demonstrated higher trust and embedded the product more deeply into daily life, both of which are classic retention drivers. Without a documented LTV methodology that accounts for this relationship, the company risks pricing and growth decisions based on generic SaaS LTV assumptions that don't reflect the actual retention mechanics of a trust-compounding AI product. This document exists to formalize that hypothesis into a measurable framework and to anchor the LTV:CAC ratio — the single most important sustainability signal for the business — on defensible methodology rather than an assumed industry-standard multiple.

## Approximate Page Count
7-9 pages

## Sections
1. **LTV Calculation Methodology** — the core formula (average revenue per user × gross margin × expected lifetime, or a cohort-based retention-curve approach) and which method is used at which stage of company maturity.
2. **Retention & Churn Modeling** — how monthly/annual retention curves are estimated pre-launch and refined post-launch, and the standard time window (consistent with Unit Economics, Doc 06) used for LTV projection.
3. **Proactivity Ladder–Retention Correlation Hypothesis** — the framework for tracking whether progression up the Phase 5 Proactivity Ladder (Doc 14) correlates with higher retention and lower churn, described as a testable hypothesis with defined leading indicators, not an assumed fact.
4. **Expansion & Household Plan Value** — how upsell/expansion revenue (e.g., individual to household plan, cross-pillar feature adoption across Productivity/Finance/Health) is incorporated into LTV.
5. **Persona-Level LTV Variance** — expected LTV differences across the Phase 1 User Personas, and how persona-level trust-building speed may plausibly affect persona-level LTV.
6. **Cohort-Based LTV Tracking** — how LTV is recalculated per acquisition cohort over time as actual retention data replaces projected retention curves.
7. **LTV:CAC Ratio Target Framework** — the target ratio range the company will use to judge growth spend sustainability, how the ratio is calculated using the Doc 06/Doc 07 methodologies, and how the target should evolve as retention data matures.
8. **LTV Sensitivity Analysis** — the methodology for stress-testing LTV against changes in churn, pricing, and trust/proactivity-progression rate.
9. **Reporting Cadence & Ownership** — how often LTV and the LTV:CAC ratio are recalculated, by whom, and how they feed into board/investor reporting alongside CAC (Doc 07).

## Deliverables
- A documented LTV formula (revenue-margin-lifetime and cohort-retention-curve variants), consistent with Unit Economics (Doc 06).
- A Proactivity Ladder–retention correlation framework with defined leading indicators for later validation.
- A persona-level LTV variance model mapped to the Phase 1 User Personas.
- An LTV:CAC target ratio framework, including the recalculation cadence as real data matures.
- An LTV sensitivity analysis framework (methodology only, no final figures).
